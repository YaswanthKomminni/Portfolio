# Developer Portfolio - Yaswanth Komminni

A premium, highly interactive, and responsive developer portfolio website designed with an elegant Editorial Serif layout, dark matte background, and high-contrast neon-chartreuse highlights.

This portfolio showcases my academic achievements, technical skill set, and projects spanning AI engineering, web development, bioinformatics, and embedded hardware.

👉 **Live Repository**: [https://github.com/YaswanthKomminni/Portfolio](https://github.com/YaswanthKomminni/Portfolio)

---

## 🎨 Design System & Visuals

- **Typography**:
  - **Headings**: `Instrument Serif` (an elegant, editorial serif style with sharp italics).
  - **Body / Metadata**: `Inter` (a clean, legible geometric sans-serif).
- **Color Palette**:
  - Background: Matte Charcoal (`#0b0a0a`)
  - Text: Pure White (`#ffffff`) & Muted Grey (`#a3a3a3`)
  - Accent Highlight: Neon-Chartreuse (`#d4f33b`)
- **Key Visual Elements**:
  - **Solid Overlap circle**: A sharp, solid neon accent circle placed behind the hero titles.
  - **Infinite Marquee Ticker**: A running horizontal banner displaying core competencies.
  - **Vertical Selected Work list**: A clean project listing replacing traditional grids, complete with hover transitions and link arrows.
  - **Metrics Block**: Large typography highlighting academic GPA and percentage details.

## 🚀 Running Locally

You can serve the static files locally using any web server. For example, using Python's built-in server:

```bash
# Clone the repository
git clone https://github.com/YaswanthKomminni/Portfolio.git

# Navigate into the project folder
cd Portfolio

# Start a local static file server
python -m http.server 8000
```

Once the server is running, open your browser and navigate to `http://localhost:8000`.
